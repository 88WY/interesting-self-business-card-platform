# 88WY - 有趣的名片平台

> 一个能更好展示自己的名片，每多一个技能就是一份成就感。

我想做一个让每个人都能酷炫展示自己技能和成长路径的名片工具。

## 🤝 如何参与共创
我非常欢迎你的想法！你可以：
